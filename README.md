# legal-medical-qa (partial MVP, host: onekami.site)

Citation-verified question answering over legal and medical documents. **Partial build:** data
layer, security libraries and ingestion core only. See `docs/STATUS.md` for exactly what is built,
what was verified, and what is missing (services, frontend, deployment files).

Setup: `uv sync --python 3.14 --all-packages`; copy `.env.example` to `.env` and fill placeholders.
